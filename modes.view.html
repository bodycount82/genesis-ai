04 · Missions

Then the clock
disappears.

A Mission is not a mood and not a long chat. It is a service driven by a signed objective: continue until every criterion is verified—or the remaining work is explicitly handed back.

Authority envelopecontract locked
ObjectiveOne unambiguous sentence.
Acceptance1–8 binary-checkable criteria, written first.
AuthorityBudget, tools, boundaries. Spending defaults to $0.
Driven byThe contract. Nothing else.
SleepNever. Fresh workers replace fatigue.
EmotionNone. The engine is not a participant.
ContinuityTransactional ledger, not fragile context.
How Missions coexist with Genesis
Chat interruption

An in-flight Worker finishes one node, Genesis answers, then the Mission resumes.

Lossless recovery

After a crash, boot reconciles and continues from the ledger. Autonomy and Work schedule around the service.

The execution engine

Done is not a feeling.
Done is a proof.

A Planner draws the graph. Fresh Workers execute one node each. A separate Verifier sees the criteria and evidence—not the Worker’s reasoning.

Six frames, one model
Intake

Drafts objective, acceptance, and authority. Never executes.

Planner

Builds the DAG and verification methods. Never executes or verifies.

Worker

Fresh context; does one node. May submit, never self-grade.

Verifier

Checks criteria and artifacts. Never sees reasoning or fixes the work.

Orchestrator

Schedules, replans, escalates, and restarts. Does no object-level work.

Auditor

Detects drift, anomalous burn, and stalls. Never edits the graph.

When it breaks

Failure has
somewhere to go.

No silent retries. No theatrical certainty. A failed node is diagnosed and routed to the right escape.

Failure routerrework
Rework, not retry. Failure reasons travel with the node. The next Worker sees precisely what failed and changes the work.
Exhaustion, infeasibility, and memory
Attempts exhausted

Default max is three. Diagnosis chooses replan, user hand-off, a permitted larger model, or a strategy council.

Strategy council

Three independent approaches plus a judge. If all conclude impossible, they draft an evidence-backed infeasibility memo.

Stall detection

No node completes within the configured window—12 hours by default—or burn rate becomes anomalous, and the Auditor triggers intervention.

One memory touchpoint

Accepted completion distills up to 4 strategies, 6 facts, and 1 outcome episode. The ledger stays exact; memory receives only lessons.
